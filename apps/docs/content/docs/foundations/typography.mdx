Nooxit uses **DM Sans** for everything and **DM Mono** for code. DM Mono is
loaded in weight 500 only, so mono text always renders medium regardless of
what the surrounding element asks for.

The Figma kit names its text styles `text-{size}/leading-{line height}/{weight}`,
which maps one to one onto Tailwind utilities. The tables below print the
Tailwind classes that reproduce each style.

## The scale

Letter spacing follows the kit: `-2.5%` (`tracking-tight`) at 30px and above,
`-0.6px` at 20 and 24px, and none below that.

## Font variables

The theme reads two CSS variables:

```css
--font-sans: var(--font-dm-sans, 'DM Sans'), ui-sans-serif, system-ui, sans-serif;
--font-mono: var(--font-dm-mono, 'DM Mono'), ui-monospace, monospace;
```

`font-heading` is a third alias that also resolves to DM Sans. It exists so
headings can be moved to a different family later without touching every
component.
