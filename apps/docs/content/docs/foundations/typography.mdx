Nooxit uses **Aspekta** for all interface text, including case numbers,
amounts and times. It replaced DM Sans on 2026-10-01, chosen over Overused
Grotesk after a client review.

There is no brand monospace. Code samples and `<code>` use the operating
system's monospace font, and nothing in the product interface does.

The Figma kit names its text styles `text-{size}/leading-{line height}/{weight}`,
which maps one to one onto Tailwind utilities. The tables below print the
Tailwind classes that reproduce each style.

## The scale

Letter spacing follows the kit: `-2.5%` (`tracking-tight`) at 30px and above,
`-0.6px` at 20 and 24px, and none below that.

## Numbers

Aspekta has proportional digits and no tabular figures, so `tabular-nums`
has no effect. Do not add it. In tables, right-align amounts and times so a
column still shares a right edge. Aspekta also has no italic; the browser
slants the upright instead.

## Removed: DM Mono

The six DM Mono styles were removed on 2026-10-01 by client decision:
`text-base/leading-6/mono`, `text-base/leading-none/mono`,
`text-sm/leading-5/mono`, `text-sm/leading-5/mono-semibold`,
`text-xs/leading-4/mono` and `text-xs/leading-4/uppercase`. Each has a sans
twin at the same size and line height. Where an uppercase label is still
wanted, add `uppercase` to a sans style.

## Font variables

```css
--font-sans: var(--font-brand, 'Aspekta'), ui-sans-serif, system-ui, sans-serif;
--font-mono: ui-monospace, SFMono-Regular, Menlo, Monaco, Consolas, monospace;
```

`font-heading` is a third alias that also resolves to Aspekta. It
exists so headings can be moved to a different family later without touching
every component. `font-mono` is for code only.
