Nooxit uses the free [Hugeicons](https://hugeicons.com) set: about 6,000
MIT-licensed icons in the Stroke Rounded style. Icons are plain data from
`@hugeicons/core-free-icons`, rendered by the `HugeiconsIcon` component from
`@hugeicons/react`.

```tsx
import { HugeiconsIcon } from '@hugeicons/react';
import { ArrowRight01Icon, Search01Icon } from '@hugeicons/core-free-icons';

<HugeiconsIcon icon={Search01Icon} strokeWidth={2} />;
```

Always pass `strokeWidth={2}`. That is 2px on the 24px grid, about 1.3px at
the usual 16px size, the same weight the system had with Lucide. Hugeicons'
own default is 1.5, which renders noticeably lighter.

`components.json` sets `iconLibrary` to `hugeicons`, so components added with
the shadcn CLI arrive in the same style.

Find icons at [hugeicons.com/icons](https://hugeicons.com/icons). The free
set also exports aliases under Lucide's names.

When an icon has to be passed around as a value (a nav item, a list), pass the
icon data and render it with `HugeiconsIcon`. The one exception is
`ChartConfig.icon`, which keeps shadcn's component API, so wrap it:
`icon: () => <HugeiconsIcon icon={X} strokeWidth={2} />`.

## Sizing

Components size icons for you. Every component carries a rule along the lines
of `[&_svg:not([class*='size-'])]:size-4`, so an icon dropped into a button,
menu item or input is 16px without being told. Add an explicit `size-*` class
only when you want something other than the default.

| Context | Size |
| --- | --- |
| Buttons, menu items, inputs, alerts | 16px (`size-4`) |
| Extra-small buttons | 12px (`size-3`) |
| Navigation menu chevron | 12px (`size-3`) |
| Empty state media, choice cards | 24px (`size-6`) |
| Resizable grip | 10px (`size-2.5`) |

## Inline icons in buttons

Buttons tighten their padding on whichever side holds an icon. Mark it so they
can:

```tsx
<Button>
  <HugeiconsIcon icon={Mail01Icon} strokeWidth={2} data-icon="inline-start" />
  Email me
</Button>

<Button variant="outline">
  Continue
  <HugeiconsIcon icon={ArrowRight01Icon} strokeWidth={2} data-icon="inline-end" />
</Button>
```

Without the attribute the icon still renders at the right size; only the
padding compensation is lost.

## Color

Icons inherit `currentColor`. Inside a component that means they follow the
component's text color automatically — a destructive menu item's icon turns
destructive without any extra class.
