Colors come in two layers. **Primitives** are the raw scales — 79 values across
nine families. **Semantic tokens** name a role (`--primary`, `--destructive`,
`--sidebar-border`) and point at a primitive, once for light mode and once for
dark.

Only ever use the semantic tokens in application code. The primitives exist so
the tokens have somewhere to point.

<Callout type="warn">
Tailwind's own palette is removed by `--color-*: initial`. `bg-blue-500` and
`text-slate-900` do not resolve — the Nooxit `blue` and `gray` scales replace
them.
</Callout>

## Using the tokens

Each token is reachable through the Tailwind utility that matches its role:

```tsx
<div className="bg-background text-foreground" />
<div className="bg-primary text-primary-foreground hover:bg-hover-primary" />
<div className="border border-border bg-muted-50" />
<p className="text-muted-foreground" />
```

The translucent tokens are registered in a single Tailwind namespace each, so
they exist as exactly one utility: `bg-muted-40`, `bg-muted-50`,
`bg-accent-50`, `bg-destructive-10`, `border-muted-40` and
`border-destructive-50`. Those names are identical to the ones in the Figma
kit, so a spec and its implementation read the same.
