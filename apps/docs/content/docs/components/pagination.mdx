## Installation

```tsx
import { ... } from 'nooxit-design-system/components/pagination';
```

## Notes

Page numbers are 40px squares with an 8px radius — not pills — and the current
page is marked with a border rather than a fill. Previous and Next are large
ghost buttons, which keeps them pill-shaped.
