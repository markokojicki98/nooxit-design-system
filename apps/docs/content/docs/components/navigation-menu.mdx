## Installation

```tsx
import { ... } from 'nooxit-design-system/components/navigation-menu';
```

## Notes

Triggers are 40px with a 6px radius and 20px side padding; they hover to muted
and turn `bg-accent-50` while their panel is open. The chevron is 12px, which
is smaller than the 16px icons used elsewhere.
