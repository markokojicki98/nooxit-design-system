## Installation

```tsx
import { ... } from 'nooxit-design-system/components/badge';
```

## Notes

Badges are 20px tall with `text-xs` semibold labels. `rounded` defaults to
`true` (a pill); pass `rounded={false}` for the 6px square badge.
