## Installation

```tsx
import { ... } from 'nooxit-design-system/components/combobox';
```

## Notes

The combobox field is the canonical Nooxit field: 40px tall (36px for `sm`),
a 6px radius, an input-colored border, and an **accent** hover — the only field
in the system that tints on hover.

The trailing icon is `chevrons-up-down` in the foreground color, and the
placeholder is foreground rather than muted, matching the kit.
