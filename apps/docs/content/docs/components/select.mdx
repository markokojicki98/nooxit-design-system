## Installation

```tsx
import { ... } from 'nooxit-design-system/components/select';
```

## Notes

The trigger is 40px (36px for `sm`) with a 16px gap between the value and the
chevron. Both the placeholder and the chevron are foreground rather than muted,
which is what the kit specifies — Input and Date Picker use muted placeholders
instead.

The check indicator sits on the **left** in a 32px gutter, so labels and items
share the same text origin.
