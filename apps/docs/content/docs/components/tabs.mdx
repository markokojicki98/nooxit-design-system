## Installation

```tsx
import { ... } from 'nooxit-design-system/components/tabs';
```

## Notes

`default` is a 40px secondary track with an 8px radius; the active tab is a
32px background pill with `shadow-xs`.

`variant="line"` is the kit's second style: a 36px row with a 1px bottom border
where the active tab gets a 2px primary underline and semibold labels.
