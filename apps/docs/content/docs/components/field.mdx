## Notes

Field is the composition layer for the pattern the Figma kit repeats on Input,
Textarea, Select, Combobox, Checkbox, Radio Group and Switch: a
`text-sm`/`leading-5` medium label, 8px gaps, a muted description, and a
**medium destructive** error message. An invalid field turns its label
destructive.

**Source** — [`src/components/field.tsx`](https://github.com/markokojicki98/nooxit-design-system/blob/main/packages/ui/src/components/field.tsx)\
**Figma** — not in the UI kit; styled from the Nooxit tokens.
