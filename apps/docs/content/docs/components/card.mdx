## Installation

```tsx
import { ... } from 'nooxit-design-system/components/card';
```

## Notes

Cards have an 8px radius, a 1px border and **no shadow**, which is where they
differ most from stock shadcn/ui.

`size` switches the padding between 24px (`default`) and 16px (`sm`), and
`CardTitle` takes `size="lg" | "md" | "sm"` for the 24px, 18px and 16px title
styles from the kit.
