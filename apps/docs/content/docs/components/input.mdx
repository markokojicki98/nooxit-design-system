## Installation

```tsx
import { ... } from 'nooxit-design-system/components/input';
```

## Notes

40px tall by default and 36px with `size="sm"` — note that this shadows the
native `size` attribute, which the component does not forward.

Focus turns the 1px border `primary`; there is no outer ring (see
[Elevation](/docs/foundations/elevation#focus-ring)). An invalid input keeps its
normal border until it is focused, then the border turns `destructive`.
