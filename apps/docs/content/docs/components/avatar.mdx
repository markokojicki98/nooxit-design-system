## Notes

Sizes follow the Figma kit: `xxs` 16px, `xs` 24px, `sm` 32px, `default` and
`md` 40px, `lg` 48px, `xl` 56px and `2xl` 64px. The `shape` prop switches
between a circle and the rounded square, whose radius scales with the size.

Fallbacks use the orange-100 / orange-950 primitives directly, which is how the
Figma kit paints them.
