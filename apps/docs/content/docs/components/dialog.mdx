## Installation

```tsx
import { ... } from 'nooxit-design-system/components/dialog';
```

## Notes

24px padding with a 32px gap between header, body and footer; the close button
is an extra-small ghost icon button with a 4px radius.

The overlay is not in the Figma kit, so it uses the Nooxit black at 10% with a
small backdrop blur.
