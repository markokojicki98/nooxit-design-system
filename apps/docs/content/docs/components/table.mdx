## Installation


## Notes

Header cells are 48px with `text-sm`/`leading-6` medium muted labels. Row
height comes from `size` on `<Table>`: `sm` 56px (the default), `md` 76px and
`lg` 96px, matching the three densities in the kit.

Rows hover to `bg-muted-50` and the footer sits on `bg-muted-50`, hovering to
`bg-muted`.
