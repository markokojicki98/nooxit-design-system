## Notes

Not part of the Figma kit; styled to match the Select trigger so the two can be
mixed in one form. Use it when you need the platform's own dropdown, and Select
when you need custom item rendering.

**Source** — [`src/components/native-select.tsx`](https://github.com/markokojicki98/nooxit-design-system/blob/main/packages/ui/src/components/native-select.tsx)\
