## Installation

```tsx
import { ... } from 'nooxit-design-system/components/checkbox';
```

## Notes

The box is 16px with a 4px radius and a 1px `primary` border on the page
background; checked and indeterminate both fill with `primary`.

The Figma check icon is painted in `foreground/main`, which would be invisible
on the filled box, so the code uses `primary-foreground` instead.
