## Installation

```tsx
import { ... } from 'nooxit-design-system/components/toggle-group';
```

## Notes

The kit spaces toggles 4px apart rather than joining them, so `spacing` defaults
to `1`. Pass `spacing={0}` for a joined segmented control.
