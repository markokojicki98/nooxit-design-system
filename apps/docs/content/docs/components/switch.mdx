## Installation

```tsx
import { ... } from 'nooxit-design-system/components/switch';
```

## Notes

44×24 by default and 36×20 with `size="sm"` — considerably larger than the
stock switch. The thumb is the page background with `shadow-lg`; the track is
`input` when off and `primary` when on.
