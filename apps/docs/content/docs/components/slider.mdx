## Installation

```tsx
import { ... } from 'nooxit-design-system/components/slider';
```

## Notes

An 8px secondary track with a primary range and a 20px thumb on the page
background with a 2px primary border — noticeably larger than the stock 16px
thumb. The kit has no focus state for the slider, so the thumb uses the standard
Nooxit focus ring.
