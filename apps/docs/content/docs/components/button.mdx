## Notes

Nooxit buttons are pills (`rounded-full`) with `text-sm`/`leading-6` medium
labels and 16px icons.

`destructive` is a separate boolean prop, not only a variant: it recolors any
variant and swaps the focus ring to `ring-destructive`. `variant="destructive"`
is kept as a shorthand for the filled destructive button.

Mark leading and trailing icons with `data-icon="inline-start"` or
`data-icon="inline-end"` so the button tightens the padding on that side, the
way the Figma kit does.
